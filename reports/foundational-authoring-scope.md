# Foundational question-bank authoring scope

Verified 2026-09-04 against current AWS Certification Exam Guides. This is an editorial scope document; it contains no exam questions and does not change production data.

## CLF-C02 — AWS Certified Cloud Practitioner

Target: 60 original draft questions.

| Domain | Guide weighting | Draft allocation |
| --- | ---: | ---: |
| Cloud Concepts | 24% | 14 |
| Security and Compliance | 30% | 18 |
| Cloud Technology and Services | 34% | 21 |
| Billing, Pricing, and Support | 12% | 7 |

Authoring boundary: foundational cloud value, shared responsibility, global infrastructure, core service identification, governance, cost and support. Avoid architecture-design depth that belongs to associate-level exams.

Official scope: <https://docs.aws.amazon.com/aws-certification/latest/cloud-practitioner-02/cloud-practitioner-02.html>

## AIF-C01 — AWS Certified AI Practitioner

Target: 60 original draft questions.

Official scope: <https://docs.aws.amazon.com/aws-certification/latest/ai-practitioner-01/ai-practitioner-01.html>

## Quality gate

Each bank must contain exactly 60 complete, distinct records in the canonical JSON schema. Each record remains `draft` until technical and editorial review. It must then pass the local validator, duplicate report, cross-bank comparison, and human technical review before any import or publication.
