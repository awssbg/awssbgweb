# Brand and team assets

Place the official, unmodified AWS SBG at LBSCEK logo at:

`assets/aws-sbg-lbscek-logo.png`

The page is already wired to use that exact path in the header. For team photos, add the image file to this folder (or a `team/` subfolder) and update the matching `photo` value in `coreMembers` in `app.js`. Photos are displayed in a fixed square frame with `object-fit: cover`.

The supplied official logo is installed at this path.
